# 媒体素材尺寸清单

> 所有尺寸都是**实测渲染值**（无头 Chrome，桌面 1440 宽 / 移动 390 宽），不是估算。
> 「建议尺寸」按 2 倍像素密度给，直接照这个准备即可；比例接近就行，容器用 `cover` 铺满、超出部分自动裁切。

| `rarebeauty-poster`<br>`assets/images/rarebeauty-render.jpg` | 加载前 / 系统开启「减少动态效果」时显示的一帧真截图 | 804×539 | 390×约 700 | **1440×952** | jpg / png / webp |

⚠️ 视频**必须是 H.264/AVC 编码**（HEVC/H.265 在 Chrome 里放不出来）。原始相机/剪辑软件导出的「无损」格式（如 QuickTime Animation、ProRes）码率高到浏览器解不动，需要先转码：

```
ffmpeg -i 原片 -an -vf scale=1440:-2 -c:v libx264 -preset slow -crf 21 ^
       -profile:v high -pix_fmt yuv420p -movflags +faststart 输出.mp4
```

（`-an` 去掉音轨：页面是静音循环播放，音轨只会白白增大体积。）

## 替换方式（三选一）

**A. 用后台（推荐）**
双击 `admin/start-admin.bat` → 浏览器自动打开 `http://127.0.0.1:5273/` →
在对应卡片上「上传替换」（也支持把文件直接拖到卡片上）。上传后立即写入，右侧预览同步刷新。
「移除」可随时恢复成 CSS 概念插画。

**B. 手改配置**
把图片放到 `portfolio/assets/media/`，然后编辑 `portfolio/assets/overrides.js`：

```js
window.MEDIA_OVERRIDES = {
  "cover-kata": "assets/media/cover-kata.jpg",
};
window.HERO_BG_OVERRIDE = { kind: "image", image: "assets/media/hero.jpg" };
```

**C. 直接覆盖同名文件**
只要替换 `portfolio/assets/` 下的同名文件即可：`images/wechat-qr.png`、`icons/*.svg`、`video/footer-scrub.mp4`。
（这类文件用后台替换时，后台会先把原占位文件备份到 `admin/_backup/`，方便随时恢复。）
