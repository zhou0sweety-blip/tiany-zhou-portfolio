准备图片的三个原则
  1. 按卡片上「建议尺寸」给图，比例接近即可 —— 容器用 cover 铺满，会自动裁切。
  2. 没有上传的槽位会保持现在的 CSS 概念插画，不会出现空白。
  3. Hero 视频必须是 H.264/AVC 编码的 .mp4（HEVC 在 Chrome 里放不出来）。
怎么改文字
  1. 在右边输入框里改 —— 停止输入约 1 秒后自动保存，左边预览实时更新。
  2. 标了 HTML 的字段可以写 <br>、<em> 等标签做换行与强调。
  3. 点字段右侧「还原」回到站点初始文案；改过的字段会标上绿点。
