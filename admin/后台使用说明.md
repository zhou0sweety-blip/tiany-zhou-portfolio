# 内容替换后台 · 使用说明

一个跑在你自己电脑上的小后台：**改文字 + 换图片/视频**，右边实时看到效果，改完自动保存到站点文件。

---

## 一、怎么打开

双击 `admin/start-admin.bat`（或在该目录执行 `node server.js`），浏览器打开 <http://127.0.0.1:5273/>。

关掉命令行窗口即关闭后台。后台只在你的电脑本地运行，不联网、不上传任何东西。

---

## 二、改文字（文字内容 Tab）

| 操作 | 说明 |
|---|---|
| 改 | 直接在输入框里改，**停止输入约 1 秒后自动保存**，左边预览**同步更新**（不用刷新） |
| 定位 | 点某个输入框时，预览会自动跳到这个字段所在的页面（首页 / Work / About / Contact） |
| 带 `HTML` 标记的字段 | 可以写 `<br>` 换行、`<em>…</em>` 强调。例：`Visual Designer<br>Based in Shanghai` |
| 还原 | 卡片右上角「还原」把该字段恢复成站点原始文案（绿底卡片 = 已改过） |
| 全部还原 | 顶部「全部还原默认」清空所有文字改动 |
| 搜索 | 按字段名、字段 key、或原文案搜索 |

覆盖范围（共 **112 个字段**）：

- **首页** Hero 三个区块（小标签 / 主标题 / 右栏链接 / 说明文字）、精选作品、关于我、工作经历（3 段 × 年份/公司/职位/职责/品牌）、合作品牌、设计理念引言、视觉档案
- **Work / About / Contact** 三页的标题、副标题、说明文字、客户标签、四组数据、设计理念引言
- **项目文案**：9 个项目 × 项目标题 / 副标题 / 年份 / 简介 / 成果标签。改一处，首页列表、Work 网格、项目详情页**同步生效**
- **页脚**：小标签、大标题、邮箱、版权行、回到顶部

> 邮箱字段会连同 `mailto:` 链接一起改。改完记得确认邮箱没有写错。

## 三、换图片 / 视频（图片 / 视频 Tab）

- 每张卡片标了**建议尺寸 / 比例 / 当前状态**，点「上传替换」或**把文件直接拖到卡片上**即可。
- 没上传的槽位保持现在的 CSS 概念插画，**不会出现空白**。
- 点「移除」恢复原状（覆盖前会自动把原文件备份到 `admin/_backup/`）。
- Hero 视频必须是 **H.264/AVC 编码的 .mp4**（HEVC/H.265 在 Chrome 里放不出来）。Hero 静态底图与视频二选一即可，都填时以最后一次上传的为准。
- **「亲气球案例」这组是原地替换同名文件**（`assets/images/qq-*.jpg`），不走 `assets/media/`、也不写进 `overrides.js`，所以 file:// 直接打开同样生效。三张 `qq-ms-*` 商详长图宽度按 100% 铺满手机屏、**高度不限**，换图后滚动行程会按新图高度自动重算。
- **「项目视频」这组**（Rare Beauty 渲染动画 + 首帧海报）同样是原地替换。视频**必须是 H.264/AVC 的 .mp4**，很多剪辑软件默认导出的无损格式（QuickTime Animation / ProRes）浏览器解不了；转码命令见 `素材尺寸清单.md` 第 7 节。

完整尺寸表见同目录的 `素材尺寸清单.md`。

## 四、改了什么文件

所有改动都写进 **`portfolio/assets/overrides.js`** 这一个文件：

```js
window.MEDIA_OVERRIDES   = { "cover-kata": "assets/media/cover-kata.png" };   // 图片
window.HERO_BG_OVERRIDE  = { kind:"image", image:"assets/media/hero-image.png" };
window.COPY_OVERRIDES    = { "hero.badge": "你好，我是" };                    // 文字
window.PROJECT_OVERRIDES = { "qinqiqiu.title": "亲气球 · 口腔护理" };          // 项目文案
```

它是用普通 `<script src>` 引入的，所以**双击 `portfolio/index.html` 直接打开（file://）也生效**，不需要服务器。上传的图片存在 `portfolio/assets/media/`。

## 五、不想开后台时

直接手改 `portfolio/assets/overrides.js` 里对应的一行，保存刷新即可 —— 效果和后台完全一样。删掉某一行 = 还原默认。字段 key 在后台每个输入框下都有（搜关键词即可对照）。

## 六、常见问题

**后台打不开 / 提示无法连接**
先确认命令行窗口还在运行；若端口被占用，执行 `node server.js 5280` 换端口，然后用 <http://127.0.0.1:5280/>。

**改了文字但站点没变**
站点是「每次渲染时套用覆盖」的，刷新一下页面即可。若是用后台预览，确认没停在别的路由页。

**改了文字，但站点上那一处没变**
有些文案位在多个页面共用（比如项目标题在首页/Work/详情页都有），改一处会同步；但若某个位置是图片/装饰文字（如字标 SVG、品牌滚动条），它不在字段列表里，需要手改 HTML 或换成图片槽位。

**中文/英文混排的字段**
带 `HTML` 标记的字段里，中英混排的分隔符（`｜` `×`）是靠 `<span class="sep">` 实现的，改文字时**别删掉这些标签**，否则间距会变。
