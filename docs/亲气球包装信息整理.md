## 二、口香爆珠包装体系（由小到大）

### 1. 便携装（最小销售单元）
- **形式**：全透明塑料滑盖盒，推拉开启，盒底印 **▲ 推开方向箭头**；内容物直接可见
- **内装物**：球形磨砂凝胶爆珠（目测直径约 5–6mm），颜色随口味（粉/绿/紫/橙）
- **正面印刷**（白色衬卡，自上而下）：毛笔「亲」字叠口味色气泡 →「亲气球」黑体 → 「<口味名>」（尖括号格式，如 <白桃乌龙味>）
- **规格**：净含量 3g；粒数 **20 粒（茉莉薄荷）/ 30 粒（白桃乌龙）**（标注见于挂卡底栏）

### 2. 挂卡装（便携盒 + 纸卡 + 吸塑罩）
- **结构**：口味色插画纸卡 + 透明吸塑罩固定便携盒，顶部开挂孔（终端可悬挂）
- **纸卡文案**：亲气球 / 口香爆珠 / 一咬就爆 一秒清新 / 口味胶囊圆标 / **「0蔗糖 SUCROSE FREE」圆形徽标**
- **合规小字**：卡顶印「**图案仅作口味描述**」
- **底栏**：凝胶糖果 · 净含量:3g · 20粒装 / 30粒装

### 3. 盒装（中盒 · 12 条装）
- **形式**：口味色卡纸彩盒（粉/绿/紫三口味），内装 **12 条独立条装**；条装带透明窗，可直接看到珠粒
- **正面文案**：亲气球 / 口香爆珠 / 一咬就爆 一秒清新 / **随时随地 畅聊更「亲」近** / 口味胶囊圆标
- **规格标注**：凝胶糖果 · **净含量:3g×12** · **360粒装**（总净含量 36g = 12 条 × 3g；360 粒 ≈ 12 × 30 粒）

### 4. 终端陈列盒（货架陈列）
- **形式**：纸板陈列架 = 前挡板 + 斜面背架（插条装）+ 顶部口号插卡；每格插约 12–13 条
- **场景口号插卡**（按口味）：
  - 粉·白桃乌龙 =「**约会来一颗**」
  - 绿·茉莉薄荷 =「**餐后来一颗**」
  - 紫·玫瑰葡萄 =「**社交来一颗**」
- **挡板**：亲气球 + 口味水果/花卉插画 + 口味胶囊 + 0蔗糖徽标

## 三、口香喷雾包装体系（由小到大）

### 1. 单瓶
- **形式**：透明 PET 细长喷雾瓶，液体呈口味色（绿/粉）；瓶身竖排「亲气球 / 口香喷雾 / 口味名」

### 2. 挂卡（单瓶装）
- **结构**：口味色插画纸卡 + 透明吸塑罩 + 顶部挂孔
- **口味圆标**：气球造型（深绿「薄荷龙井味」/ 深酒红「白桃乌龙味」）
- **文案**：亲气球 / 口香喷雾 / 一喷清新，即刻自信 / 手写体「Mint Mist」
- **卖点圆标 ×3**（描边圆，带注释角标）：**0酒精\* / 0蔗糖\*\* / 益生菌 添加\*\*\***；卡底有对应注释小字（全文过小难辨）

### 3. 中盒彩盒（8 瓶装）
- **形式**：白底 + 口味色扁平插画（薄荷龙井 = 人形侧影+薄荷叶+热带植物；白桃乌龙 = 桃子+植物+圆点）
- **文案**：亲气球（气球 logo）/ 口香喷雾 / 一喷清新，即刻自信 / Mint Mist / 口味名
- **规格**：**净含量：72mL(9mL×8)** —— 内装 8 瓶 × 9mL
- 侧面同款三卖点圆标

## 四、通用视觉与文案体系

- **主口号**：爆珠「一咬就爆 一秒清新」「随时随地 畅聊更『亲』近」；喷雾「一喷清新，即刻自信」
- **卖点标注**：0蔗糖（SUCROSE FREE）/ 0酒精 / 益生菌添加（均带 \* 注释角标）
- **合规标注**：「图案仅作口味描述」「凝胶糖果」
- **插画体系**：扁平风水果花卉（桃子、茉莉花、葡萄串、薄荷叶），马卡龙配色（粉/绿/紫/黄）
- **摄影风格**：马卡龙色圆台（粉/绿）、冰水薄荷场景（清凉感）、悬浮构图（轻盈感）、浅色统一背景
